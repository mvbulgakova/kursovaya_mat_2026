# Рациональная параметризация конических сечений

Курсовая работа по геометрии. Булгакова М. В., МПГУ, Институт математики и
информатики, кафедра геометрии им. Л. С. Атанасяна, 2026.

## Содержимое

- `tex/main.tex` — текст работы (pdfLaTeX);
- `model/` — интерактивная модель (одна страница, без зависимостей);
- `model/test/verify.js` — проверка вычислений модели и примеров из текста.

## Модель

<https://mvbulgakova.github.io/kursovaya_mat_2026/>

Можно открыть и без интернета: скачать папку `model` и открыть `index.html` в браузере.

Разделы:

- **Секущие** — секущая через рациональную точку коники и вторая точка
  пересечения в виде точной дроби; анимация, в которой рациональные точки
  заполняют кривую;
- **Целые треугольники** — прямоугольные, с углом 120° и 60°, героновы;
  для каждого показана точка на конике и секущая, которая её даёт;
- **Задачи для урока** — самостоятельная работа по вариантам с целыми ответами,
  печать вместе с листом ответов;
- **Кубики** — кратные точки nP на y² = x³ + 1 и y² = x³ − 2 при n до 200 и рост
  знаменателей.

## Проверка

```sh
node model/test/verify.js
```

## Сборка PDF

```sh
cd tex && pdflatex main.tex && pdflatex main.tex
```

В Overleaf — загрузить `tex/main.tex`, компилятор pdfLaTeX. Собранный PDF также
прикладывается к каждому запуску «Проверка и сборка PDF» во вкладке Actions.
