# Рациональная параметризация конических сечений

Курсовая работа по геометрии. Булгакова М. В., МПГУ, Институт математики и
информатики, кафедра геометрии им. Л. С. Атанасяна, 2026.

## Приложение «Рациональные точки»

<https://mvbulgakova.github.io/kursovaya_mat_2026/>

Работает в браузере компьютера и телефона, ставится на главный экран
(«Добавить на главный экран») и после первого открытия работает без интернета.
Переключатель **Школа / Вуз** меняет язык объяснений.

| Раздел | Что делает |
|---|---|
| Секущие | прямая через точку кривой и вторая точка пересечения точной дробью; анимация |
| Целые треугольники | прямоугольные, со 120° и 60°, героновы — и откуда они берутся |
| Тренажёр | варианты с QR-кодами, самопроверка с телефона, сбор результатов |
| 3D-сфера | стереографическая проекция, ящики с целой диагональю, гиперболоид (WebGL2) |
| Игра | 15 уровней: дуги, тройки, остатки, кубики |
| Кубики | кратные точки nP до n = 200 (режим «Вуз») |

### Как провести самостоятельную работу

1. Откройте **Тренажёр**, отметьте темы, число вариантов (можно по одному на
   ученика) и нажмите **Печать**. Для себя включите «лист ответов».
2. Ученики сканируют QR-код на своём листе, вводят ответы и нажимают
   **Проверить**: видно, какие задачи неверны, есть подсказки.
3. Ученик показывает или присылает код результата вида `0GGS-9AQ`.
4. Нажмите **Результаты →** и вставьте строки «Фамилия Имя КОД» — получится
   таблица с вариантами и баллами (её можно скачать в CSV).

Сервер не нужен: варианты восстанавливаются по номеру набора, а код результата
содержит контрольную сумму, поэтому опечатки и чужие коды отклоняются.

## Устройство

```
tex/main.tex              текст курсовой (pdfLaTeX)
model/index.html          оболочка приложения
model/js/core.js          точная арифметика дробей, коники, кубики, поверхности
model/js/tasks.js         задачи тренажёра, разбор ответов, коды результата
model/js/levels.js        уровни игры
model/js/lib/qrcode.js    собственный генератор QR-кодов (ISO/IEC 18004)
model/js/lib/gl.js        WebGL2: шейдеры, камера, запасной Canvas 2D
model/js/sections/        разделы приложения
model/sw.js               работа без интернета
model/test/               тесты
```

Без сборки и без зависимостей во время работы: обычные ES-модули.

## Проверка

```sh
cd model
npm ci                       # jsQR и Playwright — только для тестов
node test/verify.mjs         # ≈ 8400 проверок вычислений, задач, QR-кодов и уровней
node test/e2e.mjs            # сценарии в браузере, в том числе без сети
```

При каждом изменении GitHub Actions запускает тесты, собирает PDF курсовой
(артефакт `kursovaya-pdf`) и, если всё зелёное, публикует приложение.

## Сборка PDF

```sh
cd tex && pdflatex main.tex && pdflatex main.tex
```
